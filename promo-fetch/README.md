# 推广数据抓取（promo-fetch）

从各店铺后台定时抓取推广数据（直通车/万相台等），归档为 `<店铺名>_<日期>.csv`，
文件可直接用财务中心 T4 对应导入口导入。

原理：本机真实浏览器（Edge）+ 各店铺独立登录态。**账号密码不经过任何脚本**——
首次扫码登录一次，登录态保存在本机 `_profiles/`（不入 git），之后自动复用。

## 使用

```bash
cd promo-fetch

# 1. 首次登录（每个店铺一次；登录后关闭浏览器窗口即保存）
node login.js tmall

# 2. 日常抓取（默认抓昨天；也可指定日期）
node fetch.js tmall
node fetch.js tmall 2026-09-11
```

两种模式：

- **半自动**（当前）：脚本用登录态打开报表页，人工点「导出」，下载文件自动归档改名；
- **全自动**：在 `config.js` 里给店铺补上 `auto(page, day)` 步骤后，无人值守导出。
  （首次登录后告知 Claude，由其按实际报表页结构补写。）

## 每天定时（可选）

以管理员运行一次（时间自定，示例每天 08:30）：

```
schtasks /create /tn "推广数据抓取-天猫" /sc daily /st 08:30 ^
  /tr "cmd /c cd /d D:\claude\financial-tool\promo-fetch && node fetch.js tmall"
```

## 注意

- 登录态数周有效，过期时脚本会停在登录页——重扫一次码即可；
- 平台风控偶尔弹滑块验证，人工点一下；建议保持每天一次的低频；
- 自动化访问店铺后台属于平台用户协议的灰色地带（抓取的是本店自有数据、用于内部核算），
  请知晓风险后使用；
- 新增店铺：在 `config.js` 的 `STORES` 里照格式加一条即可。
