# 财务系统标黄需求 · 2026-09-23

对应《财务系统需求(1)(2).xlsx》Sheet1 的 10 处黄色标记。

| 单元格 | 完成后的入口与行为 |
| --- | --- |
| C10 | 损益表 → 导出录入/导入数据。按当前项目和日期导出每日原始输入，人工覆盖与各文件来源分开，保留 0 和空白；系统未保存逐笔原文件，因此此功能导出按日归集的数据。 |
| C11 | 导入可按文件日期或指定日期区间筛选，只覆盖有明确数值的日期、来源和字段。清空可指定项目、科目和起止日期；相同起止日期即单日。 |
| C12 | T4 → 导入记录。成功记录和对应数据一起保存，显示文件、操作人、日期、有效/跳过行数及原因；失败保留原数据。历史记录从本次启用后开始。 |
| C16 | 收入成本导入、收入成本录入各合并为一个入口；收入和成本仍分来源保存，单独提供其中一类时另一类保留。 |
| C17 | 收入成本录入和渠道录入可选起止日期，展开逐日独立输入，避免把一个金额自动复制至整段日期。 |
| C19 | 瑞眠 / 橘农返款。用户确认返款扣减收入：单列“返款金额”，输入正数后自动记负数扣减销售收入，已有退款金额独立保留；平台扣点随扣减后的销售收入计算。录入无需再选择返款类型。 |
| C20 | 渠道列表新增/修改，改名保留原 ID 和旧名匹配。运营费用支持增加自定义项目、改名和每日金额维护，纳入导入、损益和套表。 |
| C21 | 邮件发送 → 通讯录。支持添加、搜索、编辑、删除及邮箱重复检查，保存失败保留草稿；维护通讯录不会发送邮件。 |
| C22 | 平台扣点率改按销售收入计算，即零售收入加退货、退款及返款负数；明确录入/导入的平台扣点仍优先，其他费率基数保持原口径。 |
| C23 | 损益表固定左侧科目，分摊页固定事业部与渠道。当前月份默认月初至今天，按自然日日摊后汇总所选日期，手选月末可查看整月；明确的每日金额优先。 |

损益表、原始输入导出和套表均使用当前项目与日期范围。邮件附件明确使用当前期间全月，不随损益表的日期筛选改变。

新增共享目录与导入历史兼容旧文档；既有期间数据不做批量迁移。导入历史由服务端记录操作人和时间，并保持只追加。测试使用临时工作区及模拟收件人，不写生产财务数据，不发实际邮件。
